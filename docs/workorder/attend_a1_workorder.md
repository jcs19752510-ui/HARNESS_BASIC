- 완료되어 있어야 하는 것:

  - NeonDB PostgreSQL 접속 정보(`DATABASE_URL`)가 `.env`에 설정되어 있을 것 (**실제 값은 절대 Claude Code에게 전달하지 않음** — 로컬 `.env`만 참조하게 함)
  - `docs/trd/attend_a0_datamodel_trd.md`의 `users` 테이블이 아직 실제 DB에 없다면, 이번 세션에서 함께 생성 (SQLAlchemy 모델 + 마이그레이션)

## §2. 안 하는 것 (Out of Scope)
- 사용자(교사) 계정 생성/관리 화면 (A2에서 별도 진행 — 이번 세션은 로그인만, 계정 생성은 시드 데이터/직접 DB 입력으로 임시 처리)
- 비밀번호 찾기/재설정 기능 (요구사항에 없음, TRD에도 없음)
- 로그인 실패 로깅/모니터링 (TRD §7 미결항목, 이번엔 구현 안 함)
- 메인 화면 자체의 상세 레이아웃 (로그인 성공 후 리다이렉트만 구현, 메인화면 내용은 이후 단위)
